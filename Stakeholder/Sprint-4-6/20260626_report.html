六、之前遗留的技术债处理

遗留问题风险本阶段处理
Android 连接体验债连接卡住、误报网络被阻挡、切线状态闪烁，会直接影响用户体验。集中修复延迟探测、重连、免费额度、活动弹窗和连接状态显示。
网站部署和路由债静态站点部署路径不清，Nginx 配置过散，容易出现路由漂移。完成生产 Nginx routing 清理，并标准化静态网站 CI/CD。
基础设施安全债旧机器、旧日志、旧 artifacts 和数据库公网暴露会增加排错与安全风险。生产 MySQL 已无公网 IP，旧文件和日志清理进入持续整理。
后端 all-in-one 债主后端、BO、cron 长期混在一起，后续 FFF 复用会继承同一套包袱。BO 与 cron 已拆出，公共工具和迁移流程正在抽离。
Windows 旧客户端债旧客户端接旧后端接口，签名路径过期，无法稳定发新版。已开始升级到最新后端 API，并整理 Docker 构建和云签名路线。
