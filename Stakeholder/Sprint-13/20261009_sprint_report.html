第13阶段 · 续费改定与交接完成

报告周期 2026-09-19 至 2026-10-02 · 发布 2026-10-09

续费方案在9月21日改定为只保留续订，Android 交付三次测试版本，Windows 上测试环境，交接于10月1日完成。

一、需要决定与配合

1. 生产异地备份与恢复演练。备份与恢复手册已在10月6日写好，但演练尚未执行。这是目前风险最高的未关闭项，需要安排一次真实演练的时间窗口。
2. 百度投放网站检查。克隆站自9月25日交给投放方 Wendy 检查，至今未收到反馈。正式环境将部署到 jianyu-ip.com，上线时间取决于对方。
3. 中国地区连接验收。三协议全量铺开与中国地区可达性仍未关闭，不能用马来西亚、台湾的测试结果替代。需要安排独立的中国 QA。

9月21日续费方案改定「只保留续订」
3 次Android 测试发布（v3.9.20–22）
9月21日Windows 测试环境部署

进展交付结果边界
购买与续费规则9月18日的方案被中国同事否决后重新设计；9月21日确定只保留续订；9月24日扩展到订阅与一次性两种付费模式。当时为决策完成，实现于10月5日才完成。
支付与订阅支付网关工厂与 Stripe 生命周期梳理完成；Google 订阅迁到 v2 接口；套餐赠送天数、宽限期设置、到期无缝降级落地。渠道验收待确认。
后台专属资源购买后分配专属 IP 与专属线路的后台流程完成，并做了多项优化。这部分逻辑复杂，投入时间较多。真实购买到配发的端到端验收待确认。
Android 客户端连接状态改由引擎统一掌管，解决卡住问题；免费计时、线路列表、黑白名单、注册页区号等多项修复。v3.9.20–22 已上测试环境，设备验收待确认。
Windows 与 iOSWindows 跟随 Android 的主页与订阅界面改版，9月21日上测试环境；iOS 修复支付弹窗与网页结账处理。Windows 安装包与具体版本的对应关系待确认；iOS 真机与商店验收未关闭。
网站两个版本都已制作：一版以箭鱼自身风格为主，一版以参考站风格为主。因为收到的需求只是「复制 Glory 网站到箭鱼」，没有书面规格，所以两版并行准备。9月16日选定参考站版本，9月23日修正完毕。9月25日交投放方检查。

三、改善与商业价值

改善业务价值
续费规则按中国用户意见改定中国用户是主要用户群。保留低等级剩余天数、不抵扣价格，减少用户对续费吃亏的顾虑。
连接状态由引擎统一掌管减少 VPN 卡在连接中的情况，直接影响可用性与留存。
专属 IP、专属线路后台配发高价值订单在后台可追踪配发，减少人工处理和错配。
网站两版并行准备需求不明确时不停工等待，选定后一周内即完成修正。

五、发布边界与兼容要求

本阶段的 Android 三次发布与 Windows 一次部署都在测试环境。代码合并、测试环境部署、设备验收、生产上线是四件独立的事，本报告不把其中任何一件当作另一件。生产部署与最终验收仍为待确认。

后端继续兼容可升级的 Android、旧版 iOS HiYou 与旧版 Windows 客户端。后端的任何改动都必须保持向后兼容，这是一项长期存在的约束，也是部分清理工作必须分步进行的原因。

六、交接与协作

8月31日通知 Roy 开始交接，此后权限陆续移交，期间 Roy 继续处理更换法人与 GDPR 跟进。9月25日收到第一版交接文档，9月30日收到第二版并召开交接会议，马来西亚同步并接手。10月1日停用其 GitLab 权限。

续费方案的讨论由马来西亚、台湾与中国三方共同参与：马来西亚与台湾先达成一致，中国同事提出不同意见后共同改定方案。这一机制在本阶段起到了作用，避免按不适合主要用户群的规则上线。

七、安全与权限管控

本阶段完成交接权限收口：外部人员权限按文档逐项移交后于10月1日停用。支付渠道密钥已不再存放于数据库，改由 Key Vault 按环境命名的密文提供。

生产异地备份与实际恢复演练仍未关闭，属于最高优先级。源码权限名单本阶段没有新的复核结论。

八、阻塞与下一步

本阶段阻塞集中在等待外部反馈：百度投放站自9月25日起等待检查。工程侧的未关闭项为生产异地恢复演练、三协议全量铺开与中国地区验收、Windows 官网签名发布、iOS 真机与商店验收。

下一阶段先完成购买与续费的实现与测试，再推进后台与运行服务的权责分离，网站按反馈修正后上正式环境。具体日期以测试结果为准。

九、FFF 并行进展

本报告只覆盖 Arrowfish。FFF 的 Flutter 客户端进展由 Lex 另行汇报，FFF 的 iOS 与 macOS 由马来西亚团队负责，一并在收到 Lex 的进度报告后汇总。

FFF 保持独立的运行环境、账号、数据库、缓存、凭证与迁移历史，只复用版本化源码。

十、财务影响

本阶段以保护续费收入与会员权益为主。没有新增生产收入或成本核验，因此不把开发完成或测试发布换算成收入增长或节省金额。
