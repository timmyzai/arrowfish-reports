三、改善与商业价值

改动业务价值与限制
支付、续费与退款补齐待付款续付、支付方式切换、套餐转换及退款边界；Google 结果按订单核对，关闭自动续费后保留剩余权益。新增行为的真实支付与回调验收待确认。

财务影响本次没有新增收入、成本或退款损失的生产核验，不估算节省金额。

四、上线计划与后端兼容要求

代码合并、测试环境部署、客户端回归、地区可用性和正式验收分别记录。后端服务已在灾后恢复，不代表随后每一项支付修正都已部署或验收。

当前 API 已采用较新的共享组件，后台与定时任务主线仍使用较早版本；应先确认所需修正已覆盖所有消费服务，再验证同一账户的购买、续费、退款和权益结果。

后端仍需兼容可升级 Android 及保留使用的旧版 iOS、Windows 客户端。新客户端提交不代表旧版本已退出使用；各端、各地区验收均待相应证据确认。

五、FFF 并行进展

本次补充是源码对账，不是 Lex 新提交的进度报告：Flutter 已有套餐购买、余额支付、充值和支付事件处理代码；独享专线与独享 IP 下单的最新接线尚未合入主线。正式完成度仍待 Lex 报告与验收证据。

11月2日已有一轮开发分支合并，之后仍有未合入主线的改动；存档的接口检查结果仍列出错误，历史测试通过数不能代表当前覆盖率。

Lex 负责 Flutter 客户端报告；马来西亚团队负责 iOS、macOS 验收；Roy 负责支付网关及公司注册相关商务事项。FFF 独立运行环境、账户和数据隔离仍须单独验证。
