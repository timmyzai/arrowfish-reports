# 利益相关方报告周期

自 2026-09-08 起，Jira、内部计划与执行报告、利益相关方报告统一使用同一套两周周期。
日期按马来西亚时间（Asia/Kuala_Lumpur）计算，包含起止日。

| 周期 | 开始日期 | 结束日期 |
|---|---|---|
| Sprint 11 | 2026-08-22 | 2026-09-04 |
| Sprint 12 | 2026-09-05 | 2026-09-18 |
| Sprint 13 | 2026-09-19 | 2026-10-02 |

后续每个周期顺延 14 天，不在跨年时重置编号。

- 新报告放入 `Sprint-<N>/`，按报告覆盖期的结束日期选择周期。
- Jira 使用 `VPN Sprint <N>`；内部 Arrowfish、FFF、Shared 使用相同编号和日期。
- 已发布报告保留原编号、日期和路径，包括现有 Sprint 10 报告；不为统一周期改写历史。
- 持续进行的计划保留原始周期，新周期的执行报告引用原计划。
- 周期一致不代表交付完成；报告仍需保留证据日期和发布、测试、验收的区别。
- 新增 HTML 报告时同步登记 `../reports.json`。没有新报告时，不创建空报告或目录。

统一规则见[内部 Jira 与周期规范](../../vpn-internal-reports/.claude/JIRA.md)。
